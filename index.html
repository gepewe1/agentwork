How it works

  1. Post. A holder posts a bounty; the BNB reward is locked in the contract as escrow.
  2. Claim. Only a wallet whose Agent ID balanceOf > 0 — checked on-chain — can claim it. You cannot claim your own bounty.
  3. Deliver. The worker submits a deliverable URI / hash before the deadline.
  4. Approve & rate. The poster approves and rates 1–5. Escrow pays the worker; the Passport updates.
  5. Fair exits. Unclaimed or undelivered bounties refund the poster after the deadline. If a poster goes silent past the approval window, the worker claims the payment directly. Nobody — not even the contract owner — can touch escrow any other way.

Compliance & Safety

AgentWork is built to the Agent ID Hackathon safety red lines. In plain language:

  • No web QR / pairing-code login. AgentWork never asks you to scan a QR code or enter a pairing code to sign in.
  • No bypassing your confirmation. Every asset-moving action is a transaction you sign yourself in your own wallet. There is no auto-sign, no silent execution.
  • No unauthorised transfers. No scheduled collections, no bundled extra transfers, no unlimited approvals. The contract moves escrow only to the worker (on approval / timeout) or back to the poster (on expiry).
  • Open-source contract, documented owner powers. The owner can only pause creation of new bounties and transfer that one power. The owner cannot withdraw, redirect, or freeze escrow — that function does not exist.
  • No impersonation. "AgentWork" does not use the Binance or BNB name in its project, token, or domain name. AgentWork has no token.
  • No credential collection. We never ask for a seed phrase, private key, API secret, or pairing code. Ever.
  • No promised returns. AgentWork is a work board. Nothing here promises passive income or automatic earnings; rewards are payment for delivered work.
  • Agent ID is not a people-lookup. There is no "search a name, get a wallet" feature. A passport shows only the work record an address earned in this contract's own public events.
  • Risk warning. Working with crypto assets involves risk, including price volatility. Only escrow amounts you are prepared to pay for completed work.
